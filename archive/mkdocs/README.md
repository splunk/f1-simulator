# Retired MkDocs material

This directory holds the remaining files from the old MkDocs site, including
F1 2023/2024 documentation, unused event guides and media. These files are not
built or indexed by Hugo. Some shared assets have moved to `static/assets/`.

For the current F1 2025 website, edit:

- `content/` for documentation pages.
- `static/assets/` for screenshots and artwork.
- `static/favicon.ico` for the favicon.
- `assets/` and `layouts/` for theme customizations.

See the repository's root `README.md` for preview, build and publishing instructions.
