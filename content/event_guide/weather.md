1. Select **WEATHER AND TIME OF DAY**
2. Configure the weather and time of day:

    | Setting | Value |
    | --- | --- |
    | Quick Weather | **Clear (Dry)** |
    | Session Start Time | **Midday** |


3. Return to the **Grand Prix™ Settings** screen by pressing **O**
