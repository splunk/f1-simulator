1. Select **WEEKEND STRUCTURE**
2. Configure the weekend structure:

    | Setting | Value |
    | --- | --- |
    | Weekend Structure | **Standard** |
    | Practice Format | **Off** |
    | Qualifying Format | **Off** |
    | Session Length | **Quickfire** |


3. Return to the **Grand Prix™ Settings** screen by pressing **O**
